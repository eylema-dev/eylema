# Sınırlı Codex geliştirme adaptörü taslağı

G40 revizyon 2, `eylema-development-host` içinde projeye ait Rust sağlayıcı broker’ı ekler. Bu, **canlı kabulü tamamlanmamış bir taslaktır**: yerel fixture/süreç/ayrıştırıcı testleri ve değiştirilmemiş tam Rust kapısı geçer; kurulu CLI izin profili yapılandırması gerçek yerel ön kontrolde başarısızdır. Gerçek model çağrısı veya tamamlanmış G40 kabulü iddia edilmez. İlk üç hedefli onarım çalışma planında kayıtlıdır; somut ek onarım bakımcı onayı bekler.

Amaçlanan açık araç, mevcut yetkili ChatGPT oturumunu ve istenen `gpt-6.1-sol` / `high` ayarını kullanan Codex CLI 0.162.1’dir; SHA-256 değeri `74c6a6d263f40d65f99c27a815275f5b4ed0bcc2baecc396b4cf3255498bdfc0` olarak sabittir. Kurulu araç kurucusu gerçek yürütülebilir hash/sürümünü denetler; açık fixture taşıması ayrı etiketlenir ve kurulu sağlayıcı kanıtı iddia edemez. Araç yolları, HOME/kimlik doğrulama dizini, saat ve yetki çözümleyicisi güvenilir host girdileridir; model metninin sağladığı kimlik doğrulama değildir. Adaptör API anahtarı okumaz/kopyalamaz, yeni ücretli API yolu veya harici üretim crate’i eklemez; operasyon/eğitim veri kümesi dışa aktarmaz.

Çağrı, kabul edilmiş koordinatör/çalışma alanı bağını yeniden denetler; etkilerden önce sonlu süre payı ayırır ve görev worker’ının okuma/yazma erişimi dışındaki özel sağlayıcı dizininde sabit host argümanlarını çağırır. Shell, exec, apps, plugins, hooks, tarayıcı/bilgisayar kullanımı, alt eylemciler ve diğer etkileşimli yetenekler açıkça kapalıdır. Kullanıcı config/rules dosyaları yok sayılır ve yönerge belgesi baytları sıfırla sınırlıdır; mevcut kullanıcı dosyaları korunur. Amaçlanan görev girdileri yalnız öneri şeması ve seçilmiş prompt’tur. Mevcut tırnaklı dotted filesystem override’ları bilinen çözülmemiş yapılandırma hatasıdır; önerilen inline-table/salt okunur korunan-kök alternatifi kullanılmadan önce gerçek CLI kontrollerini geçmelidir. Kimlik bilgilerine sahip bu güvenilir sağlayıcı broker’ı G39 varsayılan-ret görev sandbox’ından ayrıdır.

Prompt 16 KiB, CLI saklanan stdout/stderr toplamı 1 MiB, süre 1–60.000 ms, JSON derinliği 16 ve düğüm sayısı 4096 ile sınırlıdır. Ayrıştırılan stringler 64 KiB ile sınırlıdır. Öneriler bir özet ve 1–16 benzersiz kabul edilmiş yol, değişiklik başına en çok 32 KiB/toplam 64 KiB metin ve açık silme anlamı gerektirir; bilinmeyen alanlar, hatalı JSON/Unicode/sayılar, yinelenen anahtarlar, kaçan/kapsam dışı yollar ve dolu silme metni reddedilir. Çıktılar güvenilmeyen veridir; değişiklik uygulamaz veya komut/PR/merge yetkisi vermez. Beklenmeyen araç olayları yetenek vermek yerine durdurur. Yakalama/ayrıştırma tamponlarının saklanan çıktı sınırına ek sonlu yükü vardır; disk kotası veya genel güvenlik sertifikası sağlanmaz.

Sağlayıcının sahip olunan süreç grubu dar macOS System/libproc SDK bağlarını kullanır. `WNOWAIT` ile `waitid`, grup temizliği bitene dek PID’yi tutarak ana sürecin çıkışını gözler; çağıran keyfi PID/sinyal veremez veya iç child’ı toplayamaz. Yalnız zombi süreçli Darwin grubu EPERM döndürebilir: en çok 127 listelenmiş üyenin sınırlı incelemesi, toplama öncesinde tümünün etkisiz olduğunu kanıtlamalıdır; canlı, bilinmeyen, taşan veya başarısız inceleme hata kalır. Testler normal çıkışı, canlı durdurmayı ve ilgisiz süreç çalışırken pipe tutan alt sürecin temizlenmesini kanıtlar. Desteklenmeyen hedefler açıkça başarısız olur. Bu güvenilir CLI grup sınırıdır; ayrıcalık değiştiren veya oturum/gruptan kaçan alt süreç desteklenen girdi değildir.

Kullanım birimleri kabul edilmiş CLI süre milisaniyesi ve 2.000 temizleme payıdır; para/token veya gizli backend HTTP istek sayısı değildir. Bildirilen token toplamları ayrı gözlemdir. Başarısız/bilinmeyen çağrılar ayrılan payı tutar; onay, doğrulama/inceleme hazır durumunu ilerletmeden gözlenen monoton saatleri ve asıl süre/iptal/yetki/saat/bütçe nedenlerini korur. Yerel toplama uzak isteğin iptalini veya ücretlendirmeyi kanıtlamaz. Kota/model/kimlik doğrulama fixture testleri açıkça sentetiktir. Gerçek yapılandırılmış sağlayıcı kabulü, güncel CI, ayrı exact-head inceleme ve bakımcı/main/devguide kapıları hâlâ gereklidir.

Yerel/fixture kontrolleri için `cargo test -p eylema-platform --test process_group --locked --offline` ve `cargo test -p eylema-development-host --locked --offline` çalıştırın. İsteğe bağlı `codex-probe --live success|unavailable|timeout` sürücüsü, bilinen yapılandırma hatası kabul edilmiş sonlu bütçe içinde onarılana dek çalıştırılmamalıdır. [Resmî CLI yapılandırması](https://learn.chatgpt.com/docs/config-file/config-reference) ve [yönerge keşfi](https://learn.chatgpt.com/docs/agent-configuration/agents-md) ayarları açıklar; yürütülmüş yerel/sağlayıcı gözlemleri belgelerden ayrıdır.
